# Вася против ИИ

Мультяшная мини-игра для Telegram: Вася — фотограф, а днём воюет с Excel-таблицами и мечтает о диване. Он отбивает камерой налетающих ИИ-агентов (Клод, Гемини, ChatGPT, Copilot, Алиса, ГигаЧат, DeepSeek).

Жми «БДЫЩ!», только когда бот рядом — он засветится. Каждый удар тратит энергию, без тапов она восстанавливается. Если зевнуть, бот зайдёт за спину и сделает массаж.

Этот репозиторий содержит только публичную веб-игру. Секретов и токенов здесь нет.
