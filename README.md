# Вася против ИИ

Мультяшная мини-игра для Telegram: человечек Вася в майке таксиста отбивает тапком налетающих ИИ-агентов (Клод, Гемини, ChatGPT, Copilot, Алиса, ГигаЧат, DeepSeek).

Тапай роботов или жми «БДЫЩ!». Есть комбо, уровни, жизни, звук и рекорд.

Игра открывается в Telegram как Mini App и как HTML5 Game.

Этот репозиторий содержит только публичную веб-игру. Секретов и токенов здесь нет.
